# AGENTS.md

## Commit messages

Write every commit message in this shape:

```
scope: short title

Big picture paragraph.

Add x
Remove x
```

- **Scope:** name the part of the repo that the commit changes, such as `web`, `index`, `install` or `release`. Use `receipts` for changes that touch the whole project.
- **Title:** write a short lowercase phrase that starts with a verb. Do not end it with a period.
- **Big picture:** explain in a few plain sentences why the change exists and what it does for the user.
- **Change lines:** write one line for each change. Start each line with `Add` or `Remove`. Do not use bullets.
- **Line length:** wrap every line of the body at 100 characters.
- **Attribution:** do not add a `Co-Authored-By` line or any other attribution.

### Wording

- Use simple, direct words.
- Write each sentence in the order subject, verb, object.
- Put one idea in each sentence.
- Do not use em dashes or en dashes.
- Describe what changed in literal terms. Do not use metaphors, slogans or filler such as "Done" or "This is the key change".
